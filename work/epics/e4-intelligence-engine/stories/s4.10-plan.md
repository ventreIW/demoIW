## Tasks

### T1 — `ScoreAndPersistScenario` use case (orchestration + idempotency)
- **Files:** `app/application/use_cases/score_and_persist_scenario.py` (new),
  `tests/unit/test_score_and_persist.py` (new)
- **RED:** With a mock `scenario_repo` (returns scenario + dataset), a fake scorer returning a
  `ScoringRun` of 3 Score entities, and a real in-memory `SQLAlchemyScoreRepository`:
  `execute(id)` persists 3 scores (`get_by_scenario` returns 3), result `scored_count=3`,
  `already_persisted=False`. Second call → `already_persisted=True`, still 3 rows. Missing
  scenario/dataset → `EntityNotFoundError`.
- **GREEN:** Implement `ScoreAndPersistScenario` + `ScorePersistResult` dataclass per design.
- **Verify:** `python -m pytest tests/unit/test_score_and_persist.py -q`; ruff/format/mypy.
- **Size:** S · **Deps:** none

### T2 — `POST /{id}/score` endpoint + container provider
- **Files:** `app/routers/scenarios.py`, `app/container.py`, `tests/test_score_endpoint.py` (new)
- **RED:** `POST /api/v1/scenarios/{id}/score` returns 201 with
  `{scenario_id, scored_count, unscored_count, already_persisted}`; 404 when the use case raises
  `EntityNotFoundError` (override the use case dependency with a stub for both paths).
- **GREEN:** Add `ScoreRunResponse`, the endpoint (catch `EntityNotFoundError` → 404), and
  `get_score_and_persist_use_case` in the container.
- **Verify:** `python -m pytest tests/test_score_endpoint.py -q`; ruff/format/mypy.
- **Size:** S · **Deps:** T1

## Execution order
`T1 ──▶ T2`. Acyclic.
