## Tasks

### T1 — `IScoreRepository` port + `SQLAlchemyScoreRepository` adapter
- **Files:** `app/ports/repositories.py`, `app/adapters/persistence/sqlalchemy_score_repo.py` (new),
  `tests/unit/test_score_repository.py` (new)
- **RED:** With the `db_session` in-memory fixture, `add_many([3 scores])` then `get_by_scenario(S)`
  returns 3 scores; category(enum)/value/explanation/scored_at intact; empty scenario → `[]`.
- **GREEN:** Add `IScoreRepository` ABC (`add_many`, `get_by_scenario`). Implement the adapter
  mirroring `SQLAlchemyClientRepository`, reusing existing score mappers + `ScoreORM`.
- **Verify:** `python -m pytest tests/unit/test_score_repository.py -q`; ruff/format/mypy on touched.
- **Size:** XS · **Deps:** none

### T2 — Container provider `get_score_repo`
- **Files:** `app/container.py`
- **RED:** (light) import `get_score_repo`, assert it returns a `SQLAlchemyScoreRepository` bound to a
  session — covered by a small test in `test_score_repository.py`.
- **GREEN:** Add `get_score_repo` mirroring `get_scenario_repo`.
- **Verify:** same test module; mypy on `app/container.py`.
- **Size:** XS · **Deps:** T1
