# S4.10 Design — Score Persistence Wiring

## Problem
Scores are computed live (prioritized endpoint: `scorer = ScoreScenario()` on every call) but never
persisted. Epic gate #1 ("every client in an active scenario has a persisted Score") is therefore
unmet. s4.9 delivered `IScoreRepository`; nothing calls it.

## Value
A deliberate scoring step that durably stores every client's Score, making gate #1 satisfiable and
giving E5 panels + the M4 E2E a real `scores` table to read.

## Approach
Thin orchestration only — no new scoring or persistence logic (both exist).

`ScoreAndPersistScenario.execute(scenario_id)`:
1. `scenario = scenario_repo.get_by_id(id)` → 404 if None.
2. `dataset = scenario_repo.get_raw_dataset(id)` → 404 if None.
3. **Idempotency:** `existing = score_repo.get_by_scenario(id)`; if non-empty, return a summary from
   `existing` without re-inserting (no duplicate rows).
4. `run = ScoreScenario().execute(dataset, id, seed=scenario.seed or 42)`.
5. `score_repo.add_many(run.scores)`.
6. Return a summary: `scored_count`, `unscored_count`, `already_persisted: bool`.

`POST /api/v1/scenarios/{id}/score` → `ScoreRunResponse`.

| Component | Change | Purpose |
|---|---|---|
| `app/application/use_cases/score_and_persist_scenario.py` | create | Orchestrate score → persist (idempotent) |
| `app/routers/scenarios.py` | modify | `ScoreRunResponse` + `POST /{id}/score` |
| `app/container.py` | modify | `get_score_and_persist_use_case` (scenario_repo + score_repo) |
| `tests/test_score_endpoint.py` | create | persist-all, idempotent, 404 |

### Legacy sweep
Net-new use case + endpoint. The prioritized endpoint's live scoring is **left as-is** (it works
without persistence; converting it to read persisted scores is out of scope). Its stale comment
"since s4.9 not done yet" is noted for a future cleanup but not touched here (scope discipline —
it's s4.5-API code and harmless).

### Lean gates
- **KISS/MVP:** thinnest orchestration; reuses `ScoreScenario` + `add_many` unchanged.
- **YAGNI:** no auto-score-on-generate, no replace-on-rescore, no prioritized-endpoint refactor.
- **Data mutation:** idempotency guard prevents duplicate-Score rows (the one real correctness risk).
- **Supply chain:** no new deps. N/A.

## Examples
```python
class ScoreAndPersistScenario:
    def __init__(self, scenario_repo: IScenarioRepository, score_repo: IScoreRepository,
                 scorer: ScoreScenario | None = None) -> None:
        self._scenario_repo = scenario_repo
        self._score_repo = score_repo
        self._scorer = scorer or ScoreScenario()

    async def execute(self, scenario_id: UUID) -> ScorePersistResult:
        scenario = await self._scenario_repo.get_by_id(scenario_id)
        if scenario is None:
            raise EntityNotFoundError(f"Scenario {scenario_id} not found")
        existing = await self._score_repo.get_by_scenario(scenario_id)
        if existing:
            return ScorePersistResult(scored_count=len(existing), unscored_count=0,
                                      already_persisted=True)
        dataset = await self._scenario_repo.get_raw_dataset(scenario_id)
        if dataset is None:
            raise EntityNotFoundError(f"Scenario {scenario_id} has no data to score")
        run = self._scorer.execute(dataset, scenario_id, seed=scenario.seed or 42)
        await self._score_repo.add_many(run.scores)
        return ScorePersistResult(scored_count=len(run.scores),
                                  unscored_count=run.unscored_client_count,
                                  already_persisted=False)
```
```json
POST /api/v1/scenarios/{id}/score  →  201
{ "scenario_id": "…", "scored_count": 60, "unscored_count": 12, "already_persisted": false }
```

## Acceptance Criteria
References Gherkin in `s4.10-story.md`.
- **MUST** endpoint persists a Score per scored client; `get_by_scenario` returns them.
- **MUST** response reports scored + unscored counts.
- **MUST** re-call does not duplicate rows (idempotency guard).
- **MUST** 404 when scenario missing or has no dataset.
- **MUST NOT** modify ScoreScenario/Score/ScoreORM/mappers/IScoreRepository; **MUST NOT** alter the
  prioritized endpoint's behavior.
