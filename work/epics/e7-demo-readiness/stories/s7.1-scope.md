# S7.1: PWA configuration scope

## In Scope
- Web app manifest completion: `id`, `scope`, `lang`, `dir`, `orientation`, `categories`, and a
  `purpose: "any maskable"` icon entry for Android adaptive icons
- Correct product identity in the manifest (`name`, `short_name`, `description`) — replacing the
  E1 scaffolding placeholder that describes industrial wastewater treatment
- Service worker hardening in `public/sw.js`: versioned cache constant, app-shell precache on
  install, stale-cache deletion on activate, network-first for navigations with an offline
  fallback, stale-while-revalidate for same-origin static assets
- An `/offline` fallback route rendered from the ES/EN message catalogs
- iOS installability: `apple-touch-icon`, `apple-mobile-web-app-capable`,
  `apple-mobile-web-app-status-bar-style`, `apple-mobile-web-app-title`
- Next.js 15 correctness: move `themeColor` from the `metadata` export to a `viewport` export
- Home page copy moved out of hardcoded Spanish JSX into `messages/es.json` + `messages/en.json`
  and corrected to the collections domain
- Vitest coverage for the manifest contract, the service worker contract, the viewport/metadata
  exports, and ES/EN key parity for the new keys
- ADR recording the decision to harden the hand-rolled service worker instead of adopting
  next-pwa

## Out of Scope
- Adding `next-pwa`, `@serwist/next`, Workbox, or any other PWA build dependency — the divergence
  from B-14's wording is recorded in the ADR
- Real-device installation testing on Android and iOS hardware (covered by the E7 demo dry-run)
- Push notifications, background sync, periodic sync, share target, app shortcuts
- Offline *functionality* beyond the fallback page — cached API responses, request queueing, and
  optimistic writes are not in this story; the app shell degrades to an explanatory page
- Accessibility work (s7.2, done) and the English translation pass (s7.3, done)
- Backend changes, database, and the standing real-Postgres E2E gate
- Regenerating or redesigning the icon PNGs — the existing 192/512 assets are reused

## Done when
- `public/manifest.json` declares `id`, `scope`, `start_url`, `standalone` display, `lang`, hex
  `background_color` and `theme_color`, and 192px + 512px icons with a maskable entry
- No user-facing string in the app describes wastewater treatment; the manifest, document
  metadata, and home page all describe accounts receivable collections
- `public/sw.js` precaches the app shell under a versioned cache name, deletes non-current caches
  on activate, serves the `/offline` page when a navigation fails, and serves static assets
  stale-while-revalidate
- Navigating to `/offline` renders localized copy in both `es` and `en`
- `apple-touch-icon` and the three `apple-mobile-web-app-*` declarations are present in the
  rendered document head
- `themeColor` is exported from `viewport`; the `metadata` export no longer carries it
- `dev/decisions/adr-010-hand-rolled-service-worker.md` exists and states the next-pwa divergence
- No regression: `vitest` green, `tsc --noEmit` clean, ES/EN message key parity holds
- Story retrospective written
