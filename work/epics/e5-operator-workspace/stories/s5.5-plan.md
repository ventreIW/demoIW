# S5.5 Plan — Communications Generator Frontend Flow

## Risks

| Risk | Impact | Mitigation |
|------|--------|------------|
| Communication entity is frozen (Pydantic frozen=True) | Low | Send endpoint creates a new Communication instance with updated status; cannot mutate existing |
| WSL cross-filesystem slowness on /mnt/c/ | Low | Run vitest with `--no-coverage`; use direct path for tsc: `node node_modules/typescript/bin/tsc --noEmit` |
| Free-tier OpenRouter rate limit during E2E | Low | Use existing mock infrastructure; E2E can test with mocked backend |
