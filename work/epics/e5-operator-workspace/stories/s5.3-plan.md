## Gate Policy

| When | Command | Scope |

## Tasks

### T1 — Types, API client, and i18n keys

**Files to create/modify:**
- `frontend/src/types/case-detail.ts` — add `ContactResultType`, `RecordContactResultRequest`, `RecordContactResultResponse`, `ClientScoreEntry`
- `frontend/src/lib/api/cases.ts` — add `recordContactResult()` function
- `frontend/src/lib/api/__tests__/cases.test.ts` (new) — API client test
- `frontend/messages/en.json` — add contact form i18n keys
- `frontend/messages/es.json` — add contact form i18n keys

**RED:** Write a test that `recordContactResult(scenarioId, clientId, { contact_result, notes })` sends a POST to `/api/v1/scenarios/{scenarioId}/clients/{clientId}/contact-result` with the correct JSON body and returns the parsed response. Mock `fetch` to return a 201 with a known portfolio response.

**GREEN:** Implement `recordContactResult()` in `lib/api/cases.ts`, add TypeScript types, add i18n keys in both locales.

**Verification:**
- `rai gate check gate-tests --scope frontend/src/lib/api/__tests__/cases.test.ts`
- `rai gate check gate-lint`
- `rai gate check gate-format`
- `rai gate check gate-types`

**Size:** XS · **Deps:** none

### T2 — ContactResultForm component

**Files to create/modify:**
- `frontend/src/components/cases/ContactResultForm.tsx` (new) — form component
- `frontend/src/components/cases/__tests__/ContactResultForm.test.tsx` (new) — form tests

**RED:** Write tests covering:
1. Form renders with type dropdown (5 options), notes textarea, and Record button
2. Submitting a valid result: mock `recordContactResult`, verify loading state (button disabled + spinner), verify success message shown, verify `onSuccess` callback called with response data
3. Submitting with API error: mock rejection, verify inline error message shown, button re-enabled
4. Notes field is optional — submit works without notes

**GREEN:** Implement `ContactResultForm` component:
- Dropdown with `ContactResultType` options (promise_to_pay, partial_payment, no_answer, disputed, paid)
- Notes textarea (optional)
- Record button
- `useState` for: `contactResult`, `notes`, `loading`, `error`, `success`
- Calls `recordContactResult()` from `lib/api/cases.ts`
- Loading state: disabled button + spinner (use existing `Spinner` pattern from `GenerateScenarioForm`)
- Error state: inline error message (use existing pattern from `CsvUpload`)
- Success state: confirmation message + `onSuccess` callback

**Verification:**
- `rai gate check gate-tests --scope frontend/src/components/cases/__tests__/ContactResultForm.test.tsx`
- `rai gate check gate-lint`
- `rai gate check gate-format`
- `rai gate check gate-types`

**Size:** S · **Deps:** T1

**RED:** Update `CaseDetail.test.tsx`:
