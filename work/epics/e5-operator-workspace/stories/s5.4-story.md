# S5.4 — Communications Generator Backend

**Epic:** E5 Operator Workspace
**Story:** s5.4
**Size:** M
**Status:** implementing
**Depends on:** s5.2, s3.2 adapter
**Owner:** Nano
**Branch:** story/s5.4/communications-generator

## Objective

Backend for generating AI-assisted communication drafts. The operator selects a client in the case detail view, chooses a channel (email, phone, WhatsApp) and tone (formal, firm, urgent), and receives a generated draft. Every draft is persisted with audit metadata (timestamp, operator, model, prompt version).

## Acceptance Criteria

```gherkin
Feature: Generate Communication Draft
  As a collections operator
  I want to generate a draft communication for a client
  So that I can review and send it from the case detail view

  Scenario: Generate a draft communication
    Given a scenario exists with id "sid"
    And a client exists with id "cid" in scenario "sid"
    And the client has invoices, payments, and a score
    When I POST /api/v1/scenarios/sid/clients/cid/communications with { "channel": "email", "tone": "formal" }
    Then the response is 201 Created
    And the response contains draft_text with the generated message
    And the response contains channel: "email"
    And the response contains tone: "formal"
    And the response contains status: "draft"
    And a Communication entity is persisted with:
      | field | value |
      | client_id | cid |
      | scenario_id | sid |
      | channel | email |
      | tone | formal |
      | status | draft |
      | draft_text | (generated content) |

  Scenario: Scenario not found
    Given no scenario with id "missing"
    When I POST /api/v1/scenarios/missing/clients/cid/communications with { "channel": "email", "tone": "formal" }
    Then the response is 404 Not Found

  Scenario: Client not found
    Given a scenario exists with id "sid"
    And no client with id "missing" in scenario "sid"
    When I POST /api/v1/scenarios/sid/clients/missing/communications with { "channel": "email", "tone": "formal" }
    Then the response is 404 Not Found

  Scenario: Client not in scenario
    Given scenario "sid1" and client "cid" belongs to scenario "sid2"
    When I POST /api/v1/scenarios/sid1/clients/cid/communications with { "channel": "email", "tone": "formal" }
    Then the response is 404 Not Found

  Scenario: OpenRouter failure returns 502
    Given a scenario and client exist
    And OpenRouter returns an error
    When I POST /api/v1/scenarios/sid/clients/cid/communications with { "channel": "email", "tone": "formal" }
    Then the response is 502 Bad Gateway

  Scenario: Prompt template uses case context
    Given a client with name "Empresa ABC", sector "manufacturing"
    And invoice "INV-001" amount 50000, due 10 days ago
    And score 65 (medium)
    When I generate a communication with channel "whatsapp", tone "urgent"
    Then the generated draft references "Empresa ABC"
    And the generated draft references "INV-001" and "50000"
    And the generated draft is in Spanish
    And the generated draft has urgent tone
```

## Out of Scope

- Real message delivery (email/SMS/WhatsApp) — "send" = status `sent` + audit row only
- Frontend flow (S5.5) — editable draft, channel/tone selector, confirm-to-send
- Multi-operator auth — demo is single-operator
