# Story: Executive dashboard — KPI cards + segmentation charts

## User Story
As a finance director (P-02),
I want to see a dashboard with KPI cards and segmentation charts for the active scenario,
so that I can understand the portfolio's value and where the risk sits at a glance.

## Acceptance Criteria

### Scenario: Dashboard loads for a scored scenario
```gherkin
Given a scenario has been scored
When I navigate to the executive page
Then I see KPI cards for total overdue, expected recoverable, cases by category, and recovery rate
And I see segmentation charts for days-overdue buckets, amount ranges, and score categories
And the scored_at timestamp is visible
And the sidebar executive link points to the executive page
```

### Scenario: Dashboard shows actionable empty state for unscored scenario
```gherkin
Given a scenario has NOT been scored
When I navigate to the executive page
Then I see an actionable empty state (not zeros)
And the empty state shows a "Score this scenario" action that navigates to the scoring page
And the sidebar executive link points to the executive page
```

### Scenario: Dashboard renders within performance budget
```gherkin
Given a scenario with 500 clients and 2,000 invoices
When I load the executive page
Then the page renders within NFR-02 budget
And no TypeScript errors occur
```

## Examples (Specification by Example)

| Input | Action | Expected Output |
|-------|--------|-----------------|
| Scored scenario ID "scenario-123" | GET /api/v1/scenarios/scenario-123/kpis | KPI aggregate with 3 segmentation dimensions |
| Unscored scenario ID "scenario-456" | GET /api/v1/scenarios/scenario-456/kpis | 409 with scored_at=null and action URL |
| Spanish locale | Navigate to /es/executive | Dashboard renders with ES copy from es.json |
