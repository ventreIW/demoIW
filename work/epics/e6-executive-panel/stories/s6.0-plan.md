## Overview

Harden `OpenRouterAdapter` so two known failure modes on the free tier degrade to `ExternalServiceError` → HTTP 502, not `KeyError`/`ReadTimeout` → 500.

**Scope (from E6 scope.md §In scope, design.md §Gemba G1):**
- Missing `choices` in response → `KeyError`/`IndexError` when accessing `data["choices"][0]["message"]["content"]`
- `httpx.ReadTimeout` (and `httpx.TimeoutException`) not caught → unhandled exception → 500

Both must raise `ExternalServiceError` so the router maps to 502 Bad Gateway (existing pattern in `cases.py:256-257`).

## Risks & Mitigations

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| `JSONDecodeError` also unhandled (noted in `test_communications_integration.py:10`) | Medium | 500 instead of 502 | Out of scope for s6.0 — pre-existing, not introduced. Park for E7 if it surfaces. |
| Timeout retry logic conflict | Low | Infinite retry on timeout | Catch `TimeoutException` *before* retry check; fail fast, no retry |
| Breaking existing retry behavior | Low | 5xx retries stop working | Only add new except clause; don't modify existing `HTTPStatusError` handling |
