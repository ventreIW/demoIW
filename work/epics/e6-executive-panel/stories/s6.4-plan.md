### Task 4: Manual Integration Test (final)
**Size:** XS · **Dependencies:** Task 3

**Manual steps:**
1. Start backend with a scored scenario (s6.1 payload fixture) + frontend dev server
2. `/es/executive` → type supported question → chart + narrative + citation render; ES copy
3. Ask a supported question whose narrative is null → chart renders, no paragraph
4. Ask an out-of-vocabulary question → honest "cannot answer" + example questions from API's supported vocabulary (no hardcoded list)
5. Unscored scenario → existing "Score this scenario" empty state
6. Kill backend / force 5xx → panel shows error; KPI dashboard above stays intact
7. `/en/executive` → EN copy parity
8. `vitest` all green; `tsc --noEmit` clean

**Note:** Live E2E against a running app is blocked in this env (no Postgres/Docker — standing blocker from E4→E7). The manual pass above is the recorded fallback; real-infra verification happens at M4/E7. Per the integration gate, contract fidelity is protected by typing `askQuestion` against the real `NlQueryResponse` shape read from `routers/executive.py` and `answer_nl_query.py`.

**AC References:** all

**Verification:** `rai gate check gate-tests --scope frontend/src/` + manual steps above

## Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Hardcoded question list drifts from backend vocabulary | AC4 asserts examples come from `supported` (never hardcoded); component reads `response.supported` |
| Null narrative renders broken/placeholder UI | AC3 explicitly tests null-narrative → chart without paragraph |
| AG2 formatter duplication | `QueryResultChart` owns its formatter, consistent with `SegmentationChart` |
| Contract drift vs. backend | Types read from real `NlQueryResponse`/`SUPPORTED_VOCABULARY` in s6.3 code, not guessed |
| Real-infra E2E unavailable (no Postgres) | Manual pass recorded; deferred to M4/E7 per standing blocker |
